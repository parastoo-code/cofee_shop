# مدیریت سفارش‌های کافه

یک برنامه ساده‌ی ترمینالی با پایتون برای مدیریت سفارش‌های یک کافه: نمایش منو، ثبت سفارش، محاسبه مبلغ کل، اعمال تخفیف و چاپ فاکتور.

## ساختار پروژه

```
coffee_shop/
├── Main.py      # منوی اصلی و اجرای برنامه
├── Menu.py      # منوی کافه (دیکشنری) و تابع show_menu()
├── Order.py     # ثبت و نمایش سفارش‌ها: add_order() و show_orders()
└── Billing.py   # محاسبه مبلغ و فاکتور: calculate_total()، calculate_discount() و print_invoice()
```

## نحوه اجرا

به پایتون ۳ نیاز دارید و نصب هیچ کتابخانه‌ی خارجی لازم نیست.

```bash
cd coffee_shop
python Main.py
```

## امکانات

| گزینه | توضیح |
|-------|-------|
| ۱ | نمایش منوی کافه و قیمت محصولات |
| ۲ | ثبت سفارش (نام محصول و تعداد) |
| ۳ | نمایش سفارش‌های ثبت‌شده |
| ۴ | محاسبه مبلغ کل |
| ۵ | چاپ فاکتور نهایی |
| ۶ | خروج |

## منوی پیش‌فرض

| محصول | قیمت (تومان) |
|-------|--------------|
| coffee | 80,000 |
| tea | 50,000 |
| cake | 120,000 |

برای افزودن محصول جدید، آن را به دیکشنری `menu` در فایل `Menu.py` اضافه کنید.

## قانون تخفیف

اگر مبلغ کل سفارش بیشتر از ۱,۰۰۰,۰۰۰ تومان باشد، ۱۰ درصد تخفیف اعمال می‌شود؛ در غیر این صورت تخفیف صفر است.

## نمونه فاکتور

```
========== فاکتور ==========
coffee     × 10
cake       × 3
----------------------------
مبلغ کل       : 1,160,000 تومان
تخفیف         : 116,000 تومان
مبلغ قابل پرداخت: 1,044,000 تومان
============================
```

## نکات

- نام محصول هنگام ثبت سفارش باید دقیقاً مطابق منو (به انگلیسی) وارد شود.
- اگر محصول در منو نباشد یا تعداد نامعتبر (غیرعددی، صفر یا منفی) باشد، پیام خطا نمایش داده می‌شود.
- سفارش‌ها فقط در حافظه نگهداری می‌شوند و با بستن برنامه از بین می‌روند.
